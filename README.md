# Asset Management Dashboard

A full-stack Asset Management Dashboard built using:

- **Frontend:** React (Vite) + AG Grid + Bootstrap 5  
- **Backend:** Spring Boot + REST APIs + MySQL  
- **Features:** CRUD operations, Pagination, Actuator Metrics, Responsive UI  

---

## Features

- View all assets in a paginated dashboard  
- Add new asset  
- Update asset details  
- Delete asset  
- Backend server-side pagination (5 records per page)  
- Spring Boot Actuator metrics enabled  
- Clean responsive UI with Bootstrap & AG Grid
